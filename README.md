# Projetos de Java - POO

Este repositório contém exercícios e projetos desenvolvidos em **Java**, focando em **Programação Orientada a Objetos (POO)**.  

Os códigos foram desenvolvidos durante o estudo de conceitos como:

- Classes e objetos  
- Atributos e métodos  
- Encapsulamento (`getters` e `setters`)  
- Construtores  
- Inner classes (`static` e não estáticas)  
- Métodos com e sem retorno (`void` e tipos específicos)  

---

## 📂 Estrutura do repositório


├─ Exercicio1.java # Trabalhando com vetores, soma, maior e menor valor
├─ Exercicio2.java # Classe Produto, objetos e métodos
├─ Exercicio3.java # Métodos com retorno, cálculo de idade futura
├─ Exercicio4.java # Inner classes: Universidade e Professor
├─ README.md # Este arquivo


---

## 📖 Descrição dos Exercícios

### Exercicio1
- Entrada de 5 números do usuário  
- Calcula soma, maior e menor valor  
- Demonstra uso de **arrays** e **loops**  

### Exercicio2
- Classe `Produto` com atributos: `nome`, `preco`, `quantidade`  
- Criação de objetos e chamada de métodos `imprimir()`  
- Demonstra encapsulamento básico (atributos públicos)

### Exercicio3
- Classe `Aluno`  
- Método com retorno: `calcularIdadeFutura()`  
- Método `void`: `apresentar()`  
- Demonstra diferença entre métodos com e sem retorno

### Exercicio4
- Inner classes `Universidade` e `Professor`  
- Uso de métodos `mostrar()` para imprimir informações  
- Demonstra **inner classes estáticas** e criação de objetos  

---

## 💡 Boas práticas aplicadas

- Nomes de classes com **letra maiúscula**  
- Métodos descritivos (ex: `imprimir()`, `mostrar()`)  
- Separação de lógica da **classe** e execução no **main**  
- Uso de `static` para inner classes quando necessário  
- Organização de código legível e comentado  

---

## 📌 Observações

- Todos os exercícios podem ser compilados e executados no **Java 8 ou superior**  
- A prática de colocar o `main` em uma **classe separada** é usada para organizar projetos maiores  
- Encapsulamento pode ser aplicado usando `private` + `getters`/`setters` para proteger os atributos
