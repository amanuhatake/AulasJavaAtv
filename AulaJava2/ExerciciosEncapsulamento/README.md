# 📚 Exercícios de Programação Orientada a Objetos em Java

## 🧠 Conceitos Aprendidos

Durante a realização desses exercícios, foram aplicados e consolidados os seguintes conceitos fundamentais de **Programação Orientada a Objetos (POO)**:

### 🔒 Encapsulamento

* Uso de atributos `private` para proteger os dados das classes.
* Criação de métodos `get` e `set` para acessar e modificar os atributos de forma controlada.
* Garantia de que os dados sempre permaneçam válidos dentro do objeto.

---

### 🏗️ Construtores

* Utilização de construtores para inicializar objetos com valores informados pelo usuário.
* Aplicação de regras de validação diretamente no construtor.
* Garantia de que o objeto já seja criado em um estado válido.

---

### ⚙️ Validação de Dados

* Implementação de validações utilizando estruturas condicionais (`if` / `else`).
* Controle de valores inválidos, como:

  * Números negativos
  * Valores fora de intervalo (ex: nota entre 0 e 10)
  * Senhas com tamanho mínimo
* Definição de comportamentos para dados inválidos (mensagens de erro e valores padrão).

---

### 🔁 Métodos (Comportamentos)

* Criação de métodos para representar ações dos objetos, como:

  * Exibir dados (`exibirDados`)
  * Atualizar valores com regras (ex: aumento de salário)
* Separação de responsabilidades entre lógica e exibição.

---

### 🧩 Regras de Negócio

* Aplicação de regras específicas conforme cada problema:

  * Saldo não pode ser negativo
  * Nota deve estar entre 0 e 10
  * Senha deve ter no mínimo 6 caracteres
* Garantia de consistência dos dados ao longo do uso do sistema.

---

## 💻 O que foi desenvolvido

Foram implementadas diversas classes simulando situações do mundo real:

* 🏦 **ContaBancaria**
  Controle de saldo com validação para evitar valores negativos.

* 📚 **Livro**
  Armazenamento de informações como título, autor e número de páginas.

* 👨‍💼 **Funcionario**
  Aplicação de bônus salarial de 10% diretamente no construtor.

* 📦 **Produto**
  Validação de preço para impedir valores inválidos.

* 🎓 **Aluno**
  Validação de nota dentro do intervalo de 0 a 10.

* 🧾 **Pedido**
  Controle de número e valor com tratamento de dados inválidos.

* 👤 **Usuario**
  Validação de senha com tamanho mínimo de 6 caracteres.

---

## 🚀 Evolução Durante os Exercícios

Ao longo dos exercícios, foi possível evoluir nos seguintes pontos:

* Melhor compreensão sobre **onde aplicar validações** (construtor vs setter).
* Entendimento da importância de manter o objeto sempre em um **estado válido**.
* Aprimoramento na organização do código e separação de responsabilidades.
* Desenvolvimento de pensamento lógico voltado para **regras de negócio**.

---

## 📌 Conclusão

Esses exercícios foram essenciais para consolidar a base de **Programação Orientada a Objetos em Java**, principalmente no que diz respeito à criação de classes bem estruturadas, seguras e coerentes com as regras propostas.
